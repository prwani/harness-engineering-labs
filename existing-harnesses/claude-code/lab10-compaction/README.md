# Lab 10 — Compaction and repository context

Use this lab's `foundry.env.example` and the [preflight](../). In an
isolated workspace, add synthetic `catalog.csv` (bowl 20) and
`service.txt` (port 3000). Ask several questions about each source;
record the exact file-grounded facts before using `/compact`.
Then change the service port to 3001 and ask again. Inspect
`/context` if your installed version exposes it.

Check the answer against the current file and compare it to the
pre-compaction notes. A condensed conversation is lossy and cannot
replace rereading source files; no specific token-saving or summary
fidelity is guaranteed without a measured run.
