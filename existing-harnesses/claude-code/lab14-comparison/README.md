# Lab 14 — Cross-harness comparison

Use this lab's `foundry.env.example` and the [preflight](../). Run a
safe read-only question on synthetic `catalog.csv` (zero-priced
bowl) and `service.txt` (port 3000). Record the model/deployment,
authentication type (not the credential), prompt, evidence,
available tool calls, actual output, usage and elapsed time if
measurable. Note which functionality was built in, configured,
manually orchestrated or unavailable.

Compare the result with the build-your-own labs only if dataset,
model, instructions, permissions and measurement definitions match.
Claude Code does not expose a bare-model baseline in this path;
do not report unobserved scores or equate a CLI usage display with
the other path's deterministic scorecard.
