# Repository map

The course outline is in [`lab-outline.md`](lab-outline.md). Each completed
lab is a runnable snapshot under `labs/`; begin with
[`labs/lab00-setup/PROMPT.md`](labs/lab00-setup/PROMPT.md) and
[`labs/lab00-setup/CONTRACT.md`](labs/lab00-setup/CONTRACT.md).

Do not import between lab folders: snapshots are intentionally standalone.

The [Codex CLI exercises](existing-harnesses/codex-cli/) follow the same
capability sequence using an existing harness. Each has its own Foundry
config example and does not read files from another lab folder. The
[Codex SDK path](existing-harnesses/codex-sdk/) is reserved for later.
